# Conway_Game_of_Life

A simple programm that runs Conway's Game-of-Life cellular automaton built with python and tkinter

  Features:
• Interactive 50x50 looped grid
• Start and Stop simulation
• Clear the board
• Random generated pattern
• Real time visualisation

  How to run:
• You can download .exe version for Windows 
• Or copy to your repository and run main.py
